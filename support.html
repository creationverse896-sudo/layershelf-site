Before you write in

Two things make almost every problem faster to solve.

1. Copy your support information

In LayerShelf, choose Help → Copy Support Information and paste the result into your email. It contains the app version, your Windows version and the database schema version. It also contains the path to your catalogue, which includes your Windows account name — remove that line if you would rather not share it, though it is often the useful part.

2. Export diagnostics, if the problem is about scanning or previews

Use Export diagnostics and attach the file. It deliberately contains no file names, paths, hashes, username or email address — only counts, versions and error summaries grouped by file type. You can open it in any text editor and read exactly what you are sending before you send it.

System requirements

  • Windows 10 or Windows 11, 64-bit.
  • Indexed formats: STL, 3MF, OBJ, FBX, STEP/STP, PLY, GLB, glTF, plus models inside ZIP archives.
  • 3D previews are available for STL, 3MF, OBJ, FBX, PLY, GLB and glTF. STEP and STP files are catalogued and searchable but do not currently render a 3D preview.
  • Geometry matching — finding the same shape saved under different names — covers STL, 3MF and OBJ.
  • Optional: 7-Zip installed, if you want models inside RAR and 7z archives to be indexed.
  • Allow a few gigabytes of disk space for thumbnails and recovery points on a large library.

Common questions

Where is my data kept? Can I move it?

Everything stays on your PC, inside your Windows profile. See the privacy policy for what each file holds. To move your catalogue to another PC, use Export library and import the file there.

Does LayerShelf change or upload my model files?

No. Scanning only reads. Nothing is uploaded — the app's only network connection is the licence check.

My licence key won't activate

Check you're online, and copy the key from your receipt email without any spaces around it. If it says the key is already in use on two PCs, deactivate one of them in Licence & sync, or email us if that PC is gone. Lost the email? Write to us from the address you bought with and we'll resend the key. The install guide covers activation step by step.

A model shows “Preview unavailable”. Is it broken?

Usually not. The file is still catalogued, searchable and safe. Previews are skipped or simplified in a few cases: very large meshes are shown at reduced detail, files above a size limit are not rendered, sliced project files contain print data rather than an editable model, and some files genuinely contain no usable geometry. The card in the library tells you which applies.

Some files are marked “Offline”

That source folder is on a drive that is not currently connected. Reconnect the drive and rescan; nothing has been lost from the catalogue.

I recycled something by mistake

Recycled files go to the Windows Recycle Bin. Restore them from there — that is a Windows action, so LayerShelf cannot undo it for you. Use Activity → Open Recycle Bin to get there quickly.

Known limitations

  • STEP and STP files are catalogued but have no 3D preview.
  • Very large models are previewed as a simplified mesh so that the viewer stays responsive.
  • Sliced project files (.gcode.3mf from Bambu Studio, OrcaSlicer and similar) hold print data rather than an editable model.
  • Cloud sync and automatic update checking are not enabled in this release.

Windows warned me when I ran the installer

The download from this website isn't code-signed yet, so Windows shows "Windows protected your PC" the first time. Choose More info, then Run anyway. If Smart App Control is switched on, Windows blocks the installer completely; email us and we'll help.
