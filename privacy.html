The short version

LayerShelf is a desktop application that catalogues 3D model files already stored on your computer. It builds that catalogue in a database inside your own Windows user profile. It has no user account and no sign-in. It collects no telemetry, no analytics and no crash reports. In this release it makes no network connections at all: the application's built-in web view is blocked from the network, and every network-capable feature in the code is switched off by configuration and cannot be enabled by a user.

We do not receive your data, because your data never leaves your computer.

What LayerShelf stores, and where

Everything below is written inside your own Windows profile, at %APPDATA%\cardiff-model-library-desktop. None of it is transmitted anywhere.

WhatContents
cardiff-model-library.dbThe catalogue: file paths and names, content hashes, your notes, tags, ratings, categories, how often you opened something, the print queue, printer notes and an activity journal. This is a plain, unencrypted database file.
Recovery points and .cmlx exportsCopies of the catalogue, encrypted with a passphrase you choose.
action-recovery\Copies of files moved by a verified move, kept so you can undo it, until you clear them from File → Recovery storage.
thumbnail-cache\Preview images generated from your models. A preview can identify a model, so treat it as you would the model itself.
boot-trace.txt, startup-error.txtStart-up stage names and any fatal error text. These may include the path to your profile, which contains your Windows account name.
Printer photosStored inside the printer-notes record, only if you add one.

What leaves your PC

Nothing — neither automatically nor as a result of anything you do in the app. This was confirmed on the packaged release: no LayerShelf process opened a remote connection during verification.

To be precise about the limit of that testing: Windows and the embedded browser engine may perform their own background activity unrelated to LayerShelf, such as certificate checks. That is outside the application's control and outside what we verified.

Features that would use the network, and are switched off

The code contains four features that would need a network connection. All are disabled in this release by blank configuration and cannot be switched on from inside the app. If a future version enables one, it will ship with its own updated privacy wording, and this page will say so.

  • Licence activation — would send a licence key and your PC's hostname to a licensing provider.
  • Update checking — would request a small update file. Nothing personal is sent, though the server hosting it would see your IP address, as with any web request.
  • Developer update channel — an internal tool, never enabled in a customer build.
  • OneDrive sync — would place an encrypted catalogue bundle, including thumbnails, into your own Microsoft OneDrive app folder.

Diagnostics and support information

LayerShelf can produce information to help diagnose a problem. It never sends any of it. You choose where it goes.

FeatureWhere it goesWhat it contains
Help → Copy Support InformationYour clipboard onlyApp version, Windows version, database schema version, and the catalogue file path — which includes your Windows account name.
Help → Report a ProblemYour clipboard onlyThe same, plus a timestamp. The app then tells you that no online reporting channel is configured.
Export diagnosticsA file you chooseVersion, schema, platform, counts, the kinds of folders scanned and when, recent job status, and error counts grouped by file type. It contains no file names, paths, hashes, hostname, username, email address or database location.

Your model files

  • Model files are never uploaded.
  • Scanning reads your files; it never modifies or moves them.
  • Recycling a file sends it to the Windows Recycle Bin, where you restore it through Windows, not through LayerShelf.
  • “Open in slicer” hands the file to whichever application Windows associates with that file type. What that application then does is governed by its own privacy policy, not this one.

Children

LayerShelf is a general-purpose tool for managing files and is not directed at children. Because it collects no personal data and has no account, it does not knowingly collect information from anyone.

Your rights

Data protection law gives you rights over personal data an organisation holds about you — including access, correction and erasure. We hold no personal data about you, because LayerShelf transmits none to us. Everything the application stores is on your own computer and under your control; you can inspect, back up or delete it at any time.

If you buy LayerShelf through the Microsoft Store, Microsoft handles the purchase and holds whatever account and payment information that involves, under Microsoft's privacy statement. We never see your payment details.

Uninstalling

If you installed LayerShelf from the Microsoft Store, Windows keeps this data in LayerShelf's own app storage and removes it when you uninstall the app. To keep your catalogue, use Export library to save a copy somewhere outside the app before uninstalling.

Changes to this policy

If this policy changes, the date at the top of the page changes with it. A version that enables any feature which sends data will say so explicitly rather than quietly amending this text.
